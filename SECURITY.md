# Security Policy

## Supported Versions

Security updates are applied to the latest minor release on the `main` branch of active `mealadev` repositories.

| Version | Supported |
| :--- | :--- |
| Latest (`main`) | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

Because Meala handles sensitive UAV telemetry, GPS coordinates, and fleet API keys, we take security vulnerabilities seriously.

**Please do not report security vulnerabilities through public GitHub issues or discussions.**

Instead, please report them privately by emailing **`security@meala.dev`** with:

1. The affected repository and version/commit hash.
2. A clear description of the vulnerability and potential impact.
3. Steps to reproduce or a proof-of-concept.

You will receive an acknowledgment within **48 hours**, and we will coordinate a fix and disclosure timeline with you once verified.
