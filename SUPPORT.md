# Getting Support

Need help setting up Meala or analyzing flight logs? Choose the right channel below:

* **Documentation:** Visit [meala.dev](https://meala.dev) for deployment guides, API references, and canonical telemetry schemas.
* **Questions & Troubleshooting:** Start a thread in [GitHub Discussions](https://github.com/orgs/mealadev/discussions) for setup help, custom parser tips, and workflow ideas.
* **Bug Reports & Feature Requests:** Open an issue in the relevant repository under [github.com/mealadev](https://github.com/mealadev) using our issue templates.
* **Security Issues:** Email `security@meala.dev` privately (see `SECURITY.md`).
